# Caja del Corresponsal

App web para llevar la caja de un corresponsal bancario Bancolombia: anota movimientos, hace los 3 conteos del día, encuentra descuadres, escanea comprobantes y avisa cuando un monto parece tener un cero de más.

Los datos se guardan solo en el celular donde se usa (con copia de seguridad en Historial).
